# 数据与逻辑（Data & Logic）

本文档是[术语表](README.md)中「关键词」小节「数据」「逻辑」两个词条的详细说明。这两个词是一对互为对照的概念，合在一篇里讲。

内容分为两个层级：

* **第一部分·功能说明**——面向开发者：这对概念是什么、引擎为什么这样切分、对日常开发意味着什么；
* **第二部分·底层实现**——面向引擎维护者：这对设计原则在引擎内部的具体体现。

开发者只需阅读第一部分。

---

## 第一部分 · 功能说明

### 数据：状态，而非事件

在 JoyEngine 中，**数据**是与逻辑相对应的概念。*组件*被设计用于容纳数据——组件本身也是数据。

理解这对概念的关键一句话：**数据是一种状态，JoyEngine 的设计原则中，总是处理状态而不处理事件。**

引擎没有全局的事件总线，也不鼓励“发生了什么→通知谁”的编程模型。取而代之，一切“发生了什么”都以**状态**的形式呈现，由感兴趣的*系统*在每帧主动读取：

| 传统事件式写法 | JoyEngine 的状态式写法 |
| --- | --- |
| 碰撞发生时回调 `onCollision(a, b)` | 物理系统把结果写进 `CollisionResult` 组件，游戏系统每帧读取它 |
| 按键按下时投递 `onKeyDown` 消息 | 输入子系统维护按键状态，系统每帧查询“现在按着吗” |
| 鼠标悬停时触发 `onHover` | UI 系统更新 `MouseOn` 组件，游戏逻辑读取该状态 |
| 动画到达某时刻时发事件 | 动画系统把当帧触发的事件写入实体的动画事件数据，系统当帧取走 |

状态式的好处：**时序确定**（所有系统在同一帧内看到一致的世界快照）、**天然可并行**（读状态不需要锁与回调链）、**可序列化**（编辑器与存档直接保存的就是状态本身）。

### 逻辑：描述数据如何被处理

**逻辑**是与数据相对应的概念。逻辑读取数据、处理数据以及更新数据。*系统*是逻辑的载体。

纯粹的逻辑本身应当是无副作用的——它只描述“数据在输入之后被怎样处理和更新”这一过程。落到的实践准则：

* 系统的更新函数里，做的是“读取切片内的组件数据 → 计算 → 写回组件数据”；
* 游戏的演进 = 状态在逻辑驱动下逐帧变化，而不是一串被触发的回调；
* 需要跨帧记住的东西是**状态**，应当放进组件（或系统实例的私有成员），而不是藏在逻辑的闭包与全局变量里。

### 这对概念如何配合

* *组件*（数据）描述“世界现在是什么样”；
* *系统*（逻辑）描述“世界每帧如何变化”；
* *实体*把数据组织成可寻址的集合；
* *切片*让逻辑只看到它关心的那部分数据。

把“是什么”与“怎么变”分开，是引擎几乎所有能力的基础：多世界并行、编辑器直接检查与序列化组件、切片的批量处理，都依赖这一分界。

## 第二部分 · 底层实现

> 这对概念没有独立的“实现文件”——它体现为引擎各子系统的一致设计选择。本部分列举引擎内部遵守这一原则的代表性机制，均可在对应文档找到详细展开。

### 状态式设计的引擎内实例

* **命令缓冲**：即便是结构变更（增删组件/实体/系统）这种“副作用”，也被改写为“提交状态变更请求”——命令先作为数据进入缓冲，在下一帧的单线程同步点统一应用（见[世界](world.md)第二部分）。
* **碰撞结果即数据**：物理系统不回调游戏逻辑，而是把接触点写进 `Physics2D::CollisionResult` 组件（含 `Contact` 数组），由游戏系统当帧消费（见[物理](physics.md)）。
* **输入即状态**：输入子系统每帧泵取设备状态并更新可查询的数据面，没有按键消息队列（见[输入](input.md)）。
* **动画事件即数据**：动画系统把当帧命中的事件写入实体的动画事件数据，供系统当帧读取（见[动画](animation.md)）。

### 并行安全与数据归属

“数据归属清晰”是并行执行的根（见[世界](world.md)的多世界并行一节）：

* 组件实例只属于一个世界、一个实体，系统对切片内数据的读写不存在跨世界竞争；
* 同一更新阶段内的系统并行执行，其安全性依赖“系统只通过组件数据交换信息”这一约定——若系统绕过组件用全局变量通信，就破坏了引擎的并行前提。

### 逻辑的载体与私有状态

* C++ 系统是注册进世界的实例（继承 `jeecs::game_system`，见[系统](system.md)），实例本身的成员是系统合法的私有状态；
* Woolang 脚本系统的函数与闭包同理（towoo 包装，见[脚本](script.md)）；
* 但应注意：私有状态不参与切片、不参与序列化，跨帧的游戏可见状态应放进组件。
