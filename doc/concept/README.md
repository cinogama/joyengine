# JoyEngine 术语和概念

## 引擎的基本概述

JoyEngine 是一个基于 ECS 框架的游戏引擎。使用 C++/Woolang 进行游戏开发。

游戏开发期间，开发者所做的事情基本围绕着以下事项：

* 准备所需资源文件（纹理、模型、动画等）
* 编写 *组件”*
* 在编辑器中使用特定的组件集合创建 *实体*，调整实体在 *世界* 范围内的位置以及实体的组件成员值
* 编写 *系统*，观察和修改特定的组件数据，实现游戏的逻辑

## 术语表

简单介绍一些关键的术语：

#### ECS 术语

* 世界

世界（World）是容纳系统和组件实例的空间；引擎允许同时有多个世界实例存在。这些世界实例将 *并行* 地执行系统的逻辑。

* 组件

组件（Component）是纯粹的数据，组件本身不包含实际的游戏逻辑，但是在实际开发中，允许带有一些简单的、类似访问器的方法。

* 实体

实体（Entity）在引擎中是一个“不存在”的概念。实体是若干特定组件实例构成的集合——实体只是这样的集合关系本身。

当文档中提到实体一词时，其同义词是 `组件集合`。

* 系统

系统（System）是纯粹的逻辑集合。系统中的 *Update* 更新函数负责观察世界中的特定组件切片，并获取这些组件实例，读取或修改它们的成员数据。

* 宇宙

宇宙（Universe，这个词有点中二……）是储存所有世界的容器，通常情况下，这个容器本身是一个单例。

#### 游戏术语

* 帧

JoyEngine 使用画面帧/逻辑帧同步。宇宙会负责对所有世界发起一轮*工作*调用。在工作调用（NORMAL_JOB_FOR_WORLDS）期间，执行所有的系统的更新逻辑。

综合来说，引擎完成一轮工作循环即被称为**一帧**

* 工作

工作（Job）是 JoyEngine 的最基础的逻辑调用机制。引擎会在一帧中调用所有注册到宇宙中的工作——所有系统的逻辑更新也只是工作的一部分。

* 差异时间

差异时间（DeltaTime）是引擎提供的一种时间机制。笼统地说，差异时间指的是上一帧的开始时间，与当前帧开始时间的时间差。此时间由引擎负责计算，因为计算方法的不同，延伸出 *实时* 和 *平滑* 两种差异时间。

* 系统更新

更新（Update）是系统的逻辑函数，引擎将负责调用这些函数，一帧一次地执行游戏逻辑。

* 变换

变换（Transform）用于表示实体的空间关系，即描述实体的绝对/相对位置信息，实体本身的旋转和缩放情况。

* UI

UI，即 UserInterface。UI被设计用于在屏幕上以独特的定位方式，描述用户界面上的一些渲染内容。因为其独特的定位方式，它的渲染流程和普通实体并不一样

* 渲染

渲染（Renderer）指的是将世界中，满足特定切片要求的组件集合，将相关的组件数据呈递并产生人眼可见的画面的过程。负责执行渲染的系统在引擎内部被称为 *渲染系统* 或者 *渲染管线*（渲染管线一词在不同领域有不同含义，这和 *可编程渲染管线* 一词情况类似，在文档中，上述词汇仅特指术语表中的含义）。

渲染的过程一般涉及到 *摄像机* 和待渲染的实体。

* 摄像机

摄像机（Camera）指的是带有特定的摄像机组件的实体；渲染系统会为每个摄像机渲染一次所有待渲染的实体。将渲染结果输出到屏幕，或者由 `RendToFramebuffer` 组件指示的目标缓冲区。

* 动画

动画（Animation）是一种随着时间变化而改变实体组件数据，并借此最终影响渲染结果，借助人体的视觉暂留效应产生独特视觉效果的机制。

* 物理

物理（Physics）通过物理引擎，模拟实体如同现实中的物体一般发生受力、碰撞、摩擦和反弹等物理现象时的变换变化。

JoyEngine 通过 Box2D 模拟 2D 物理。

* 音频

音频（Audio）能够播放音频，并模拟发声源出于特定场景下的声音效果。

* 瓦片地图

瓦片地图（TileMap）是一种快速绘制 2D 场景的机制。

#### 数学概念

* 标量和矢量

标量指的是只有大小的量，矢量既有大小，也有方向。

JoyEngine 提供 ivec2，vec2，vec3，vec4 作为矢量类型。

* 四元数

四元数是一种表示三维空间中旋转的常用形式。

JoyEngine 提供 quat 四元数类型。

#### 关键词

* 数据

在 JoyEngine 中，数据是与逻辑相对应的概念。组件被设计用于容纳数据——组件本身也是数据。数据是一种状态，JoyEngine 的设计原则中，总是处理状态而不处理事件。

* 逻辑

在 JoyEngine 中，逻辑是与数据相对应的概念。逻辑读取数据、处理数据以及更新数据。纯粹的逻辑本身应当是无副作用的——它只描述数据在输入之后被怎样处理和更新这一过程。
