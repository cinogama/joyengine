# je_animation_sample_buffer_clear

## 函数签名

```c
JE_API void je_animation_sample_buffer_clear(je_animation_sample_buffer_t* buffer);
```

| `buffer` | `je_animation_sample_buffer_t*` | 采样缓冲 |

| ``void`` | — |
