# WebGL 支持

在开始构建之前，请先做好以下准备工作：

* 安装 `cmake`，正确地设置环境变量，确保可以直接调用 `cmake`
* 安装 `emscripten`，正确地设置环境变量，确保可以直接调用 `emcmake`
* 安装 `mingw`，正确设置环境变量，确保可以直接调用 `make`

完成以上准备工作之后：

* 进入游戏项目，按照正常流程打包
* 将项目打包产生的镜像索引文件及镜像文件，复制到 `./preloads` 目录内
* 将项目使用的 C++ 模块目录，整个目录拷贝到 `../module` 目录内，注意：module 目录在上层目录，不在当前目录中
* 执行 `build_release.bat` 等待构建完成

构建完成的产物将被储存到 `./output` 目录中。如果需要测试，可以执行 `start.bat`，此批处理会启动一个演示 http 服务器，然后打开浏览器，连接到此服务器。
